# Анонимный трекер оценок партнёра

Веб-приложение для централизованного сбора анонимных оценок партнёра по пяти параметрам и приватной аналитики для администраторов. Учебный проект по реальному заказу FL.ru №5514303.

Версия 2.0: респонденты открывают публичную ссылку с любого устройства, ответы сохраняются на сервере в SQLite, а статистика и выгрузка доступны только после входа в админку.

## Что реализовано

- Публичная часть: старт, опрос и экран благодарности.
- Пять оценок по шкале 1–10: уверенность, чувствительность, инициативность, адаптивность, общее впечатление.
- Обязательные поля «Пол» и «Возраст» без случайного значения по умолчанию.
- Клиентская и серверная валидация, защита от двойной отправки.
- Отправка ответа через `POST /api/responses` и хранение в SQLite.
- Отсутствие публичной статистики: данные видны только администраторам.
- Вход администратора по логину и паролю, серверные сессии на 8 часов.
- Несколько равноправных администраторов.
- Обзор: количество ответов, средний балл, последний ответ, пять карточек средних, два графика Chart.js и текстовые таблицы под ними.
- Таблица ответов с фильтрами по полу, возрасту и датам, пагинация по 50 записей.
- Экспорт CSV с учётом фильтров.
- Удаление всех ответов с модальным подтверждением.
- Управление администраторами: создание, включение/отключение, смена пароля.
- Rate limit, проверка Origin, `HttpOnly`/`SameSite=Strict` cookies, scrypt-хэши паролей.
- Адаптивная вёрстка от 360 до 1440 px и базовая доступность.
- 43 автоматических теста.

## Быстрый старт

### Windows: запуск двойным кликом

В корне проекта лежит `start-tracker.bat`.

1. Дважды кликните по `start-tracker.bat`.
2. При первом запуске файл сам установит зависимости, если их нет.
3. Запустятся API на `http://127.0.0.1:3001` и Vite на `http://127.0.0.1:5173/`.
4. Браузер откроется автоматически. Публичная часть: `http://127.0.0.1:5173/`, админка: `http://127.0.0.1:5173/admin`.
5. При первом запуске в консоли будет показан логин и пароль первого администратора. Сохраните их.
6. Чтобы остановить трекер, закройте окно консоли или нажмите `Ctrl+C`.

Если Vite уже запущен, повторный запуск просто откроет браузер.

### Через терминал

Требования:

- Node.js 20+ (проект проверен на Node.js 24.20.0).
- npm 10+.

```bash
npm install
npm run dev
```

- Публичная часть: `http://127.0.0.1:5173/`.
- Админка: `http://127.0.0.1:5173/admin`.
- API: `http://127.0.0.1:3001/api/health`.

Vite проксирует `/api` на backend, поэтому cookie сессии остаются same-origin.

### Production-сборка

```bash
npm run build
npm start
```

Fastify раздаёт `dist/` и API на одном порту:

- Публичная часть: `http://127.0.0.1:3001/`.
- Админка: `http://127.0.0.1:3001/admin`.

Для доступа с других устройств в локальной сети задайте `HOST=0.0.0.0` в `.env` и откройте порт `3001`.

## Первый администратор

При первом запуске, если в базе ещё нет администраторов:

- логин берётся из `INITIAL_ADMIN_LOGIN` (по умолчанию `admin`);
- пароль берётся из `INITIAL_ADMIN_PASSWORD`;
- если пароль не задан, сервер генерирует его и показывает в консоли **один раз**.

Создать администратора вручную:

```bash
npm run admin:create -- manager
```

Если пароль не указать, он будет сгенерирован и показан один раз:

```bash
npm run admin:create -- manager МойДлинныйПароль123
```

Сменить пароль:

```bash
npm run admin:password -- manager
```

Публичной регистрации нет. Остальные администраторы добавляются из раздела «Администраторы» в админке.

## Переменные окружения

Скопируйте `.env.example` в `.env` и измените значения при необходимости.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `HOST` | `127.0.0.1` | Адрес сервера |
| `PORT` | `3001` | Порт API и production-статики |
| `DB_FILE` | `data/tracker.sqlite` | Путь к файлу базы |
| `INITIAL_ADMIN_LOGIN` | `admin` | Логин первого администратора |
| `INITIAL_ADMIN_PASSWORD` | генерируется | Пароль первого администратора |
| `COOKIE_SECURE` | `0` | Включает `Secure` у cookie; обязательно для HTTPS |
| `TRUST_PROXY` | `0` | Доверять заголовкам reverse proxy |
| `LOG_LEVEL` | `warn` | Уровень логов Fastify |
| `BACKUP_DIR` | `backups` | Каталог резервных копий |

`COOKIE_SECURE=1` также включается автоматически при `NODE_ENV=production`.

## Как проверить основной сценарий

### Публичная часть

1. Откройте `http://127.0.0.1:5173/`.
2. Нажмите «Начать опрос».
3. Не выбирая пол и возраст, нажмите «Отправить оценку» — появятся две ошибки, фокус перейдёт к первой.
4. Выберите пол и возраст, измените слайдеры, отправьте форму.
5. Убедитесь, что открылся экран «Спасибо!», а публичной статистики нет.
6. Откройте страницу на другом устройстве в той же сети и отправьте ещё один ответ.

### Админка

1. Откройте `/admin` и войдите с логином и паролем первого администратора.
2. Проверьте количество ответов, средний балл, последний ответ, карточки и графики.
3. Откройте «Ответы», примените фильтры по полу, возрасту и датам.
4. Выгрузите CSV и откройте его в Excel.
5. Создайте второго администратора, выйдите и войдите под ним.
6. Отключите второго администратора и убедитесь, что его сессия завершена.
7. Проверьте удаление всех ответов: без подтверждения действие не выполняется.

## API

Все административные методы требуют cookie `tracker_session`.

| Метод | Путь | Доступ | Назначение |
|---|---|---|---|
| `GET` | `/api/health` | Публичный | Проверка сервера |
| `POST` | `/api/responses` | Публичный, 20/мин | Сохранить ответ |
| `POST` | `/api/auth/login` | Публичный, 10/мин | Вход |
| `POST` | `/api/auth/logout` | Публичный | Выход |
| `GET` | `/api/auth/me` | Сессия | Текущий администратор |
| `GET` | `/api/admin/stats` | Сессия | Статистика |
| `GET` | `/api/admin/responses` | Сессия | Список с фильтрами и пагинацией |
| `GET` | `/api/admin/export.csv` | Сессия | CSV с фильтрами |
| `DELETE` | `/api/admin/responses` | Сессия | Удалить все ответы |
| `GET` | `/api/admin/admins` | Сессия | Список администраторов |
| `POST` | `/api/admin/admins` | Сессия | Создать администратора |
| `PATCH` | `/api/admin/admins/:id` | Сессия | Статус или пароль |

Пример отправки ответа:

```bash
curl -X POST http://127.0.0.1:3001/api/responses \
  -H "Content-Type: application/json" \
  -d "{\"gender\":\"m\",\"ageGroup\":\"25to35\",\"scores\":{\"confidence\":7,\"sensitivity\":5,\"initiative\":8,\"adaptability\":6,\"overall\":7}}"
```

Подробное описание API, коды ошибок и примеры — в [`docs/SPEC.md`](docs/SPEC.md).

## Данные и резервные копии

- База по умолчанию: `data/tracker.sqlite`.
- SQLite работает в режиме WAL; рядом появляются `-wal` и `-shm`.
- Каталог `data/` исключён из git.
- В базе нет имён, контактов и IP-адресов.
- IP используется только в памяти rate limiter и не сохраняется.
- Ответы хранятся до ручного удаления администратором.
- Старые данные из `localStorage` не мигрируются: v2 использует только сервер.

Создать резервную копию:

```bash
npm run backup
```

Копия сохраняется в `backups/tracker-<дата>.sqlite`.

Восстановление:

1. Остановите сервер.
2. Замените `data/tracker.sqlite` файлом копии.
3. Удалите `data/tracker.sqlite-wal` и `data/tracker.sqlite-shm`, если они остались от старой базы.
4. Запустите сервер.

## Безопасность и приватность

- Пароли хранятся только как scrypt-хэши.
- Сессионный токен хранится в базе только как SHA-256.
- Cookie: `HttpOnly`, `SameSite=Strict`, `Secure` при HTTPS.
- Сессия действует 8 часов.
- Публичной регистрации нет.
- Все данные и CSV доступны только администраторам.
- Публичный API не отдаёт ответы и статистику.
- Rate limit: 20 ответов в минуту, 10 попыток входа в минуту.
- Для изменяющих запросов проверяется `Origin`, если он передан браузером.
- Заголовки: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`.
- Админка закрыта от индексации через `robots.txt` и `X-Robots-Tag`.
- Нет сторонней аналитики, CDN и внешних шрифтов.

## Известные ограничения

- Нет строгой защиты «один ответ с устройства»: публичную ссылку можно переслать, повторные ответы ограничиваются только rate limit.
- Нет восстановления пароля по email: пароль меняется через CLI или из админки.
- Все администраторы равноправны, ролей и журнала действий нет.
- SQLite рассчитан на один сервер и до 1 000 ответов.
- Нет автоматических резервных копий: используется `npm run backup`.
- VPS, домен и HTTPS подключаются отдельным этапом.
